# Wagamama challenger promo model

This repo includes a Google Sheets-compatible template for sizing a Wagamama
lapsed-customer challenger promo.

- Workbook: `models/wagamama_challenger_promo_model.xlsx`
- Usage guide: `docs/wagamama_challenger_promo_model.md`
- Generator: `tools/create_wagamama_promo_model.py`

Upload the workbook to Google Drive, open it with Google Sheets, and use
**File > Save as Google Sheets** to convert it into a native GSheet.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

### How to run the Streamlit app on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
